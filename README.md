# Fightcade User Finder

Chrome extension to search and locate Fightcade users. Developed by Àlex Llaó.

## Development

```bash
pnpm install
pnpm dev
```

## Validation and packaging

```bash
pnpm validate
pnpm package
```

Development happens on the `development` branch. Fightcade integration will be implemented once its behavior has been specified.
